ATLAS

RSNA's Annotated Library of AI Systems

ATLAS is the library of AI models and datasets hosted by the Radiological Society of North America (RSNA). Information about each model or dataset is stored as a JSON-language "card" on the ATLAS site, where it is indexed by title, keywords, and radiology subspecialty content codes.

Information contained within each card is based on the ROADMAP ontology, an interlinked set of concepts that standardizes the terms used to describe AI models and datasets. ROADMAP includes synonyms, abbreviations, and defintions of the terms.

JSON Schemas

Machine-readable schemas for ATLAS model and dataset cards, aligned with the ROADMAP ontology.

  • schema/2026-12/ current Model and dataset schemas, three conformance profiles (minimal, procurement-ready, regulatory-ready), and the changelog describing what changed since 2025-11.
  • schema/2025-11/ Prior version, kept for reference and for cards that still declare it.

About

The Radiological Society of North America (RSNA) is a non-profit organization of more than 54,000 members that represents professionals spanning the full breadth of radiologic subspecialties in more than 160 countries around the world.

ATLAS is RSNA's library of AI models and datasets. Each model or dataset is described by a JSON "card" conforming to one of the schemas above. The source for these schemas, and for the repository this site is published from, is github.com/RSNA/ATLAS.

For questions, contact RSNA's Informatics Department at informatics {AT} rsna {DOT} org.
